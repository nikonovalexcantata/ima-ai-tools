Claude Code skills

A curated marketplace for the team, published from nikonovalexcantata/ima-ai-tools. Install what is useful to you and skip the rest — nothing here is required to work on any repo.

One-time setup

Register the marketplace once per user, then install per skill.

# once per user
claude plugin marketplace add nikonovalexcantata/ima-ai-tools

# then, per skill
claude plugin install grilling@ima-ai-tools

# pick up new entries later
claude plugin marketplace update ima-ai-tools

The two commands above install for your user only. Add --scope project to a command to write the entry into the repo’s .claude/settings.json. Git tracks this file. Each person who opens the repo and trusts the folder then gets the plugin automatically. Add --scope local to write the entry into .claude/settings.local.json. Git ignores this file. The plugin is then active only for you and only in this repo.
